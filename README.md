# Lumina Camera Android

Native Android wrapper (WebView) for the Lumina Ultra Camera web app.

## Features
- Loads the live camera app from GitHub Pages
- Camera + microphone permissions handled
- getUserMedia works inside WebView
- Back button navigates in the web app
- In-app updates: since it loads the live URL, any web update is instant

## Build
1. Open in Android Studio
2. Sync Gradle
3. Run on device (camera permissions required)

Or use any online HTML-to-APK builder pointing at the live URL.

Package: com.lumina.camera
